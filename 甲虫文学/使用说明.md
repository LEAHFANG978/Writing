# 《甲虫文学》使用说明｜V5.0

本轮只修订规范、人物、时间线与目录，不写新小说，不覆盖原著或历史生成正文。

1. 每次写新作或改规范，先完整阅读[原著](原著/快消市场部变形记-原始上传.txt)，再读[原著风格与人物基准](原著风格与人物基准.md)。找不到全文必须报告缺失并停止新创作。
2. [人物档案](人物档案.json)与[职业时间线](职业时间线.md)是连续性维护源；最新用户要求优先。现在时5年多，维护锚点T66，Hair Care，Band 2，无新增晋升。
3. 分卷是主文档维护源；作品目录.csv登记64个计划。01、58是两篇冻结历史稿，未通过当前原著基准。原著独立登记，不冒充新生成作品。
4. 执行 `python 甲虫文学/校验与汇编.py` 重建主文档；执行 `python 甲虫文学/导出Word.py` 导出主文档Word，保留既有小说Word。脚本不能代替阅读或人工风格检查。
5. 阅读[V5.0对照与修改记录](V5.0-原著对照与修改记录.md)了解冲突。旧版报告仅记录历史，不再作为八年工龄等冲突设定的依据。AGENTS.md已写入长期规则。

原著保留上传字节及换行，SHA-256见原著登记.json；新作2000—3000字目标不适用于删改原著。下载受客户端影响，本地生成不代表附件一定可下载。
